# Subject hero images (school tracks)

Place **WebP or PNG** files here so each subject track page can show a full-width hero:

| File         | Subject              |
|-------------|----------------------|
| `math.webp` | Math                 |
| `english.webp` | English / ELA     |
| `science.webp` | Science           |
| `history.webp` | History & social studies |

Recommended: **1792×640** or similar wide aspect (~2.8:1), exported WebP for size.

**Art direction:** Pixar-style 3D, bright and friendly, classroom-safe, on-brand with Sparki (use your established image prompts). If a file is missing, the app shows a colorful gradient hero instead—no broken layout.

Paths in code: `subjectTrackVisuals.ts` → `public/school-subject-heroes/*.webp`.
