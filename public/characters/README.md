# Homework Adventure Video — character loops

Place optional **looping MP4** files here (used by `/homework/adventure-video`):

| File | Character |
|------|------------|
| `sparki.mp4` | Sparki |
| `byte.mp4` | Byte |
| `pixel.mp4` | Pixel |
| `zap.mp4` | Zap |

If a file is missing, the UI shows a static emoji fallback. Keep clips short and muted-friendly (the `<video>` is played **muted** with `playsInline`).
